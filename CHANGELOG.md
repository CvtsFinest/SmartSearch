# Changelog

## 1.0.0 - 2026-08-17

Initial public release.

### Features
- Interactive word/phrase search
- Exact and fuzzy OCR matching
- User-selected screen search region
- Automatic scrolling up or down
- On-screen result highlighting
- Highlighted screenshot capture
- Find-first and find-all modes
- Previous search-region reuse
- Basic end-of-scroll detection
- Results saved under `~/Documents/smartsearch-results/`
- PyAutoGUI failsafe and Ctrl+C stop support
